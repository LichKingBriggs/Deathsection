How to Find & Join Deathsection

Follow these steps in ARK: Survival Ascended to find the Deathsection Cluster in the in‑game browser and connect to any of our PvE, PvP, or overhaul servers.

Step‑by‑Step Instructions

This is all done from the in‑game server browser inside ARK: Survival Ascended.

Finding Deathsection in ARK: Survival Ascended

  1. Go to Join Game from the main menu.
  2. Turn on Show Player Servers ✅ in the filters.
  3. In the search bar, type Deathsection.

Once you search for Deathsection, you should see multiple servers in the list — both PvE and PvP, plus our overhaul modes. Select the map you want, then click Join.

If the Servers Don’t Show Up

If you don’t see any Deathsection servers in the list after searching, try these quick checks.

Troubleshooting Tips

  • Double‑check your spelling — make sure you typed Deathsection correctly.
  • Refresh or re‑query the server list after turning on Show Player Servers.
  • Confirm you’re in the correct browser for ARK: Survival Ascended, not an older game version.
  • If you still can’t find it, join our Discord and ask in support: discord.gg/deathsection.
